# 海关视觉实训智能识别系统

面向课程实训的本地 Web 项目：使用已有 YOLO 模型处理图片和摄像头画面，保存检测记录并由人工复核；同时提供内部文字通讯、云端大模型助手和管理功能。

**当前是 V1.2 功能迭代版本，不是全部验收完成的正式产品。** 模型输出的 `sus` 框只是候选检测结果，不代表身份确认、犯罪概率、去重人数或执法结论。未检出也不等于“安全”。

文档整理日期：2026-09-07。这里的版本、测试数和部署状态均为有日期的快照，不能替代启动时检查。

## 2. 当前能做什么

| 模块 | 用户操作 | 当前边界 |
| --- | --- | --- |
| 账户与个人中心 | 注册、登录、切换用户／管理入口、查看资料、改密码、退出 | 权限由后端校验；首次认证的内置管理员需改密 |
| 工作台与图片识别 | 选择或拖拽 1～10 张图片，提交、看进度、取消未执行任务 | 使用真实文件和后台任务，不填充演示检测结果 |
| 摄像头识别 | 授权本机摄像头，预览、送检、暂停、恢复、停止和保存结果 | 已有实现；实体摄像头及跨设备场景待实测 |
| 检测记录与人员名单 | 筛选记录、查看原图／派生图、人工复核、人工关联档案 | 名单不参与训练；关联不代表模型识别了姓名 |
| 内部通讯 | 选择其他用户私聊、管理员邀请建群、收发文字／Emoji、加入公共房间 | 只面向本系统账户；无外部通讯平台接入；尚未完成局域网部署验收 |
| 智能助手 | 选择智能体，预览实际外发文本，确认后问答、查资料、生成摘要／报告草稿 | 需要有效厂商配置；真实厂商尚未验收；不自动外发图片或内部聊天 |
| 数字人 | 助手左侧形象展示，右侧文字对话 | 当前为成年男性图片占位；已有受控 GLB 渲染入口，但无正式 3D 资产验收 |
| 管理中心 | 用户权限、云端配置、智能体、实训资料、受限聊天检索、审计日志、统计大屏 | 管理角色也不能读取未参加的私人会话 |

普通用户只能使用已授予的功能，管理员管理普通用户；只有超级管理员可调整 `USER`／`ADMIN` 角色。内置 `admin` 受保护，不能被删除、停用、改名或降权。

## 3. 启动与首次使用

### 已配置好的当前工作区

在项目根目录执行以下命令，并保持终端中的服务运行：

```bash
PYTHONPATH=backend backend/.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

打开 [本机系统入口](http://127.0.0.1:8000/)。**不要双击 `index.html` 使用 `file://` 打开**，否则无法按同源方式使用后端。前端由这个服务一起提供，不需要再启动另一套前端开发服务器。

如果端口已被占用，先确认是否已有本项目服务运行，不要随意结束占用端口的其他程序。单实例运行，保持一个 Uvicorn worker。手动启动的服务可在其终端按 `Ctrl+C` 正常停止；停止前应结束摄像头并确认没有需要保留的在途操作。

### 新电脑或全新环境

先阅读 [后端运行说明](backend/README.md) 的“新环境准备”。需要 Python 3.12、锁定依赖、符合项目基线的 SQLite 驱动、可信本地模型资产；前端依赖重建时需要 Node.js/npm。当前依赖主要在 macOS arm64 验证，不能假定 Windows 安装已经通过。

不要覆盖现有 `.env`、数据库或媒体目录来“重新安装”。现有 API Key 的加密依赖应用密钥，直接换密钥可能使其无法解密。

### 登录与密码

1. 初始化时，系统在缺少内置 `admin` 时创建它；已有正常账户不会因重启被重置。
2. 全新初始化的默认用户名是 `admin`，初始密码是 `admin123`。这是公开的初始化凭据，**不是现有系统修改后的密码**，也不应用于对外开放的部署。
3. 先登录验证，再进入首次改密。普通匿名访问应显示登录页面。
4. 当前统一要求新密码为 **12～128 个字符**，不能与旧密码、用户名或初始化密码相同。输入不会自动去掉首尾空格；请留意输入法和大小写。
5. 点击输入框右侧眼睛可切换明文显示；个人中心可修改本人密码。改密后旧会话失效，需要重新登录。
6. 普通会话绝对有效期 8 小时，空闲期限 30 分钟；后台轮询不无限续期。登录持久化不等于永久免登录。

早期测试曾要求最低 8 位和更长登录保留，新版接口文档已明确统一为上述规则。若要再次改变，需先确认需求并同步前后端契约，不能只改输入框限制。

## 4. 推荐的使用顺序

1. 登录后先检查个人信息及授权功能。
2. 在图片识别中上传有权用于实训的图片，等待任务终态；“失败”和“未检出”是不同结果。
3. 在记录详情中查看结果，必要时人工复核及关联虚拟档案。原图和带水印结果图分别保存。
4. 内部通讯中选择真实系统用户；管理员建立群聊时填写名称并勾选联系人，建成后从群聊列表进入。
5. 使用公共房间前阅读并确认历史可见性说明。管理员聊天检索／CSV 导出也限本人参与的会话。
6. 使用助手前，由有权限的管理员配置厂商和智能体。能力测试会产生 1～2 次云端文本请求，需要确认费用；测试成功后仍须显式启用。每次业务发送前检查完整文本预览，确认后才发送。
7. 对助手生成的内容查看引用并人工核验。来源失效后系统会隐藏旧结果，但无法收回已经阅读或复制出去的内容。

## 5. 常见问题与维护

| 现象 | 建议先检查 |
| --- | --- |
| `Load failed`／无法连接 | 是否用 HTTP 服务地址；服务是否运行；浏览器地址和服务端口是否一致 |
| CSRF 相关错误 | 是否切换过 `localhost`／`127.0.0.1`、Cookie 是否被限制、精确 Origin 是否匹配；不要通过关闭 CSRF 解决 |
| 一进入就是修改初始密码 | 是否处于已验证的首次改密受限会话；匿名访问不应进入该页；不要擅自重置数据库 |
| 修改后的密码不能登录 | 检查账户名、空格、大小写、所用入口和是否连接了另一份数据库；记录请求编号，不把密码发给维护者 |
| 建群或发送没有反应 | 记录页面提示、时间、请求编号；检查权限和群成员状态，不要连续新建请求造成重复操作 |
| 摄像头不可用 | 检查浏览器授权、设备占用；跨设备访问需可信 HTTPS；页面预览不等于推理已成功 |
| 助手不可用 | 检查配置是否测试并启用、智能体是否有效、来源权限是否变化；失败不应自动重复云端计费调用 |

管理员可在“运维与审计”按请求编号追踪。默认文件日志位于 `backend/logs/application.log`，单文件 2 MiB、5 个轮转备份。数据库另有运维和审计事件，**数据库日志还没有自动保留期清理**，需关注磁盘容量。

提交问题时提供：发生时间与时区、模块、复现步骤、预期／实际结果、请求编号、脱敏截图。不要提供密码、API Key、会话 Cookie、完整私人聊天或未经许可的人像。

升级前使用 [后端说明](backend/README.md) 中的备份脚本，保存数据库一致性快照。完整恢复还需要对应媒体、配置和程序版本，单个 `.db` 备份不等于完整系统备份。

## 6. 局域网与安全范围

同一个网络上的用户应访问同一台服务器，而不是各自双击 HTML 或各自建立数据库。目前已核验的启动方式仅监听本机回环地址。不能只把监听地址改成 `0.0.0.0` 就认定局域网部署完成。

部署到局域网前需要：明确服务器地址、可信 HTTPS、精确允许的 Origin、安全应用密钥、合适防火墙和多设备测试。当前开发密钥不能直接用于开放网络。不要把数据库放在跨机器网络共享文件系统上。本项目暂不接入外部通讯网络。
