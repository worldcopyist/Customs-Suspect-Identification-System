## 先说明记录边界

当前仓库此前没有 Git 提交历史。以下较早记录来自现有源码、实施说明、测试记录和用户反馈的回溯，能说明已知目标、处理方向和当前结果，但**不能还原每一次保存、每一行改动、每个精确时间或未保留的失败尝试**。因此，本文把“已核对”“历史记录”“待验证”分开，不把历史描述写成独立验收结论。

从本文件建立后，后续每一个独立修改都应先新增一个 `CHG-NNNN` 条目，写明问题、依据、原因或尚未确认的假设、修改过程、影响、实际测试结果、回退方式和遗留项；同时更新英文手册。不要删除旧条目，应以新的更正或替代条目说明变化。

## 历史主要变更

### CHG-0001：建立 V1.2 全栈实现基础

- 状态：历史已实现。
- 问题：早期页面以视觉演示为主，前端、后端、数据持久化和真实业务流程不完整。
- 处理：以 FastAPI、SQLite、受控本地媒体和原生 ES Modules 建立同源系统，补充认证、用户、档案、检测、批次、摄像头、复核、聊天、云端配置、智能体、助手、日志和大屏模块，并使用 Alembic 迁移维护结构。
- 证据：现有源码、`docs/V1.2_IMPLEMENTATION.md` 和历史测试记录。
- 注意：原技术架构目标提出 Vue 3/Vite，但现有前端仍是原生 ES Modules；不能写成“架构完全对齐”。

### CHG-0002：修复首次进入错误跳转到改初始密码、登录注册加载失败和 CSRF 问题

- 状态：历史已实现。
- 问题：匿名打开服务时出现“修改初始密码”，登录和注册还曾显示 `Load failed` 或接口参数错误。
- 原因判断：匿名状态与“已验证但必须改初始密码”的受限会话未充分区分；前后端对同源 Cookie、CSRF 和错误返回的处理需要统一。该判断来自历史修复记录，不是本次重新复现的网络追踪。
- 处理过程：匿名用户进入登录页；只有用正确密码完成认证、且账户被标记为首次改密时，才进入受限改密页。前端集中处理 API 请求、CSRF 初始化、一次明确的 CSRF 失效恢复及请求编号提示。
- 影响：`ui/core.js`、认证接口、会话和安全服务。
- 历史验证：隔离登录、注册、改密和匿名入口检查通过。
- 遗留：尚未做生产环境下的登录限流和多浏览器长期会话验收。

### CHG-0003：认证页面、密码可见性和个人中心改密

- 状态：历史已实现。
- 问题：需要替换认证页左侧背景、删除装饰柱体、在密码框提供眼睛按钮，并让用户可在个人中心修改密码。
- 处理过程：认证页改为背景和文字组合；密码框右侧按钮可切换明文／密文；个人中心新增改密；密码不写入日志或文档。
- 规则冲突：早期反馈要求最少 8 位，后续接口文档明确统一新密码为 12～128 位，因此当前前后端按 12 位执行。已存在的密码哈希未因该变更被重置。
- 遗留：不同浏览器的完整视觉回归尚未验收。

### CHG-0004：登录状态持久化和失效行为

- 状态：历史已实现。
- 问题：用户希望登录状态持久化，但也曾出现因空闲过期的提示。
- 处理过程：使用服务端会话 Cookie，普通会话最长 8 小时、空闲 30 分钟；账户停用、角色／权限变化、改密和退出可撤销会话。后台轮询不应无限续期；退出请求未获服务端确认时，前端不假装已安全退出。
- 风险：持久化不是永久免登录，长时间、断网和多设备场景仍需专项验收。

### CHG-0005：清理示例数据并连接工作台、记录和人员名单

- 状态：历史已实现。
- 问题：工作台、检测记录、图片页出现示例记录、虚拟账户、演示数字和不一致表格；用户要求清零示例内容。
- 处理过程：已加载页面改读数据库和真实请求结果，移除被加载 UI 中的示例统计／检测记录；检测结果保留人工复核和人工关联历史。统计使用记录与检测框口径，不称作“识别人数”。
- 风险：不代表真实业务库已清理；不应为了清零页面而删除用户真实记录。

### CHG-0006：图片上传、批量检测和摄像头流程

- 状态：历史已实现。
- 问题：页面使用示例图片，用户需要点击／拖拽真实图片；摄像头停止按钮无反应。
- 处理过程：实现 1～10 张图片受控上传、逐项排队、取消、状态展示、原图与独立水印派生图、记录详情和人工复核；摄像头使用浏览器授权、暂停／恢复代际、停止轨道、过期帧丢弃和当前结果留档。
- 历史验证：真实 YOLO 子进程在两张合成图上完成推理并可读取媒体。该结果不证明模型识别精度。
- 遗留：实体摄像头授权、切换、断线恢复、跨设备 HTTPS 未验收。

### CHG-0007：补齐内部通讯、私聊、群聊与公共房间

- 状态：历史已实现。
- 问题：内部通讯页面消失；联系人无法点击私聊；建群只设 ID 或确认无反应；消息发送无效；联系人和群聊需要分区并限系统内部使用。
- 原因判断：早期页面事件和后端写入流程不完整；另有历史问题是通知异常会把已经提交的群聊写入误报成失败。
- 处理过程：补充私聊、管理员邀请建群、成员增删、群解散后只读历史、公共房间告知加入／退出、在线状态、文字和 Emoji、精确消息游标分页、成员范围内检索与 CSV 导出。通知失败与持久写入结果分离。
- 历史验证：隔离环境建群幂等、浏览器选择会话、发送并持久显示消息通过。
- 遗留：尚未完成同一局域网多设备部署和压力测试；项目不接外部通讯网络。

### CHG-0008：添加可维护日志与安全诊断

- 状态：历史已实现。
- 问题：用户希望为整个系统添加日志，方便定位群聊、登录和页面问题。
- 处理过程：加入请求编号、路由模板、关键审计／运维事件、受限浏览器诊断及轮转文件日志。运行命令关闭 Uvicorn 原始访问日志，减少搜索词或查询参数进入日志的风险。
- 边界：不记录密码、密钥、会话 Cookie、请求正文、完整私人聊天正文、原始搜索 URL 或堆栈。
- 遗留：数据库运维日志没有自动保留期清理，需要容量策略和备份恢复演练。

### CHG-0009：补齐大模型、智能体和数字人页面

- 状态：历史已实现。
- 问题：LLM 设置、数字人和聊天窗口消失；配置块溢出、发送按钮无反应；希望管理员管理 API、温度和数字人资产。
- 处理过程：增加厂商配置、加密保存 API Key、显示掩码、显式能力测试、智能体版本、助手对话和确认发送；发送前展示实际外发文本，确认后最多一次调用。数字人页面保留成年男性图片占位并支持受控本地自包含 GLB 渲染与失败降级。
- 边界：测试成功不会自动启用厂商；网页不允许任意 3D 上传；当前没有正式 GLB。真实厂商、费用和 3D/GPU 验收均未完成。

### CHG-0010：助手回答事实约束与引用撤权

- 状态：历史已实现。
- 问题：报告／摘要不能凭空编造检测事实，需要用户查看来源，来源权限变动后不能继续展示失效内容。
- 处理过程：`customs-text-v3` 由后端冻结检测事实，业务模式只接受严格结构化结果；引用仅可指向有权访问的记录或资料块；查看引用和展示历史时重新检查所有权、版本、状态和内容哈希；模型输出工具调用被拒绝。
- 历史验证：离线测试覆盖不合法结构、工具调用、引用与撤权。
- 重要限制：这些规则降低编造风险，不证明大模型对资料的自然语言解释正确，仍必须人工核验。
