## 工作项

- 数据迁移：人员、人工复核历史、批次、派生媒体、摄像头代际、在线心跳、公共房间、智能体、运维日志。
- 认证：双入口、12 字符新密码、8 小时／30 分钟会话、精确 Origin、CSRF 一次恢复。
- 检测：真实文件预览与批量任务、摄像头暂停恢复／保存、记录筛选详情复核关联、人员 CRUD。
- 通讯：持久私聊群聊、公开历史确认加入／退出、在线、全局入口、成员受限搜索 CSV。
- 助手：独立厂商配置、多智能体热更新、完整外发预览确认、可恢复输出、安全 Markdown、知识管理。
- 管理：用户权限、个人密码、只读健康、审计运维日志、精确统计大屏。
- 前端：统一 API 客户端及单一事件处理，去除旧叠加式页面实现；服务仅暴露允许的静态资产。
- 验证：临时数据库自动化测试、实际 HTTP 联调、浏览器检查；不向现有业务库插入测试聊天或检测记录。

## 需要明确区分的验收边界

真实 DeepSeek／千问调用需有效凭据且用户明确确认；测试桩通过不等于云端验收。
摄像头需浏览器授权和目标硬件；局域网摄像头需可信 HTTPS。
正式 3D 形象需用户提供且经部署人员审核的自包含 GLB，默认占位图不代表 3D 验收完成。
新版撤销网页 YOLO 配置写入及任意 3D 上传入口；不新增语音、聊天附件、全站私聊审计。

## 本轮实现结果

上述工作项均已有前后端入口和同源接口实现，历史演示脚本保留但不再加载。新页面展示数据库或真实请求结果，不填充示例统计。实现映射见 `IMPLEMENTATION_BOUNDARIES.md`，运行步骤见 `../backend/README.md`。

重点修复与补强：

- 匿名 CSRF 会话先判断未登录，不再错误进入初始改密；只有通过密码验证的受限会话进入改密页。
- 修正群聊通知的 anyio 跨线程调用，并把通知失败与持久写入分离；通知异常不会让已提交写操作变成失败响应。
- 私聊／群聊选择、联系人邀请、持久消息、分页游标、群解散只读状态和全量未读汇总已连接。
- 密码不自动去除空格；新密码按最新文档为 12–128 位，保留已有密码哈希。退出失败不会假装会话已撤销。
- 日志提供请求编号、事件类型、审计动作、时间及权限筛选；运行文件按轮转保存，不记录请求正文、密码、密钥或聊天正文。启动时关闭原始访问日志，避免检索关键词进入 URL 日志。
- 图片任务取消／认领采用条件更新；重启后未执行任务保留原截止时间重新调度，已执行任务失败而不自动重跑；模型摘要／配置变化时拒绝使用新配置偷偷执行旧任务。
- GLB 入口验证文件结构、自包含资源、30 MiB／10 万三角形／2048 纹理预算；加载失败释放资源并保留图片与文字聊天。尚无正式模型资产验收。
- 大模型测试显式选择协议及温度上下限，至多 1–2 次固定文本请求，事前说明费用，任一步失败即停止；验证成功不自动启用。温度边界测试不是中间所有参数或业务正确性的证明。
- 旧厂商验证指纹不再被当作新版能力验证，需明确重新测试；API Key 保留。角色参数与已验证能力匹配，旧准备单在配置变化后失效。

能力测试接口在原字段外增加 `test_stream`、`temperature_min`、`temperature_max`；上下限同时为 null 表示不发送温度。相同边界只发一次，不同边界各发一次。响应增加 `test_call_count`、`capabilities`、`version`，`usage` 为各次测试用量数组。失败或结果未知时，同一幂等键不会再次外发；需要刷新配置后显式新建测试。

## 2026-09-07：业务回答与引用补强

新请求采用 `customs-text-v3` 模板：

- SUMMARY／REPORT 的记录数、来源时间、模型摘要、阈值、候选框及置信度、人工复核和虚拟人员编号关联由后端冻结事实生成。姓名默认不外发。单条事实超过 800 字符直接拒绝，不能截掉“人工关联”等限定后继续发送。
- 模型在摘要／报告中仅以严格 JSON 选择固定的待核对事项及证据标签；不接受自由编造事实字段或任意处置建议。报告含基本情况、检测结果、人工复核、人工关联、限制与待确认事项、来源清单和 AI 提示。
- KNOWLEDGE 要求逐条回答要点绑定证据、提供资料范围说明；未知标签、外部链接、额外字段和非结构化正文会被拒绝。引用关联不保证句子真实，界面明确要求逐项核对原文。
- 新增 `GET /api/v1/assistant/requests/{id}/citations/{label}`。仅答复所属用户可查看已引用来源；每次重新验证检测权限、版本、资料状态、块版本及内容哈希。返回受控片段或检测事实，不接受模型生成的跳转 URL。
- 助手历史和最终答复提供来源按钮；后台定期检查访问权，失效后隐藏旧结果并关闭引用窗口。无法收回用户已看到或自行复制的内容。
- 幂等重放旧准备单也重检当前来源，避免通过缓存响应绕过撤权；业务模式不发布未经校验的正文增量。
- 有正文同时返回工具调用也视为协议错误，不显示为合格答案，更不会执行工具。仅此软件规则不能证明所有自然语言输出都正确。

本轮新增测试覆盖两个报告模式、人工关联最小外发、知识引用、来源失效后历史隐藏、旧预览重放拒绝、未知引用／编造字段／非法核对事项、流式与非流式工具调用拒绝。均为离线厂商测试，不产生真实云端调用。
